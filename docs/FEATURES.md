## 1. 영상 ↔ 상품 연결
- **상태**: ✅ · **마지막 변경**: 2026-11-12
- **동작**
  - 상품 상세 오른쪽에 리뷰 영상 패널. 썸네일 목록만 보이다가 [실행하기]를 누를 때 YouTube 플레이어(iframe)를 만든다 → 누르기 전에는 유튜브로 데이터가 가지 않음
  - 방문자 조회는 DB 캐시만 읽음, 유튜브 검색은 상품 등록 시 1회 + 매일 스케줄러

  - 광고는 YouTube가 결정 — 사이트에서 막지 않음 (개발자 정책)
- **코드 위치**: `backend/.../youtube/`, `frontend/views/youtube/YoutubePanel.tsx`
- **API**: `GET /api/products/{id}/videos`

## 4. 언어 = 시장

  - 언어 결정 순서: 직접 고른 값(쿠키) → 브라우저 언어 → 접속 국가(배포 환경 헤더) → 한국어

  - 설계 의도: README "영문 페이지 설계 의도" 참고
- **남은 일**: 수집 원본 달러 가격 저장·표시(끝자리 보정), 영문 하단 대표자 표기
- **코드 위치**: `frontend/lib/i18n/` (config · dictionaries · server · format), `models/api/siteApi.ts`

## 15. 포인트
- **상태**: ✅ · **마지막 변경**: 2026-11-26
- **동작**
  - 1P = 1원. 주문서에 보유 포인트 표시, 사용할 포인트 입력·전액 사용, 상품 금액 / 포인트 / 결제 금액 분리 표시
  - 포인트로 전액 결제하면 결제창 없이 바로 주문 완료
  - 주문서를 만들 때는 확인만, **결제가 확인된 순간에 차감** → 결제를 포기한 주문에 포인트가 묶이지 않음
  - 잔액 차감은 `UPDATE … WHERE 잔액 >= 사용량` 한 번 → 동시에 두 주문을 해도 음수가 되지 않음
  - 카카오페이 결제 후 포인트가 부족하면 결제 자동 취소
  - 마이페이지 "내 포인트" 카드: 잔액 + 최근 내역 5건
- **남은 일**: 구매 적립, 리뷰 작성 적립 같은 적립 정책
- **DB**: `backend/db/points-avatar.sql` — `member.point_balance`, `orders.point_used`, `point_history`
- **API**: `GET /api/auth/me/points`

    - 포인트로 받기: 주문 금액 전액을 즉시 포인트로 적립 (재구매 유도)
  - 취소된 주문에 "포인트로 환불 완료 · 40,000P 적립 · 사유" 같은 결과 표시
- **DB**: `orders.cancel_reason`, `orders.refund_type`
- **테스트**: 백엔드 자동 테스트 6개 (포인트 사용 · 환불 · 전액 포인트 결제 · 잔액 부족 · 결제 전 취소 · 프로필 사진)
